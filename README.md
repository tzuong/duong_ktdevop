# devops-test-thuyduong

DevOps CI/CD demonstration project.

## Project Information

Project name: devops-test-thuyduong

Branch: main

## Technologies

- HTML
- CSS
- JavaScript
- GitHub
- Jenkins
- IIS
- Telegram Bot

## CI/CD Pipeline

GitHub Push
↓
Jenkins
↓
Checkout
↓
Install Dependencies
↓
Build
↓
Deploy
↓
Website
↓
Telegram Notification

## Deployment

The website is deployed automatically by Jenkins.

## Notifications

Telegram Bot sends notifications for:

- Deploy Started
- Deploy Success
- Deploy Failed

## Debug

A build error is intentionally created to test Jenkins failure detection.

After identifying and fixing the error, the code is pushed again and Jenkins performs a successful deployment.
